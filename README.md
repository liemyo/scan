# Scan Pasar — liemyo.github.io/scan

Riset pasar & harga dalam tabel, 100% di browser/HP (tanpa komputer atau server sendiri).

- **Google Maps**: Google Places API (New). Tempel API key di situs (disimpan hanya di browser).
- **Facebook Marketplace**: dijalankan di cloud oleh Apify (`apify/facebook-marketplace-scraper`). Tempel Apify API token di situs.
- Tabel + ringkasan harga (terendah/tertinggi/median), rekomendasi harga beli/jual, link WhatsApp, ekspor CSV. Tampilan kartu di HP.
