🔎 Scan Pasar

Riset pasar & harga: Facebook Marketplace dan Google Maps dalam satu tabel.
Facebook tidak punya API publik dan wajib login, jadi scan dijalankan oleh helper di Mac Anda (fb_scan.py) lewat Google Chrome profil yulius.krisnawan (sesi Facebook yang sudah login). Jalankan helper dulu: python3 fb_scan.py. Panduan lengkap ada di repo.
Tanpa API key: kosongkan kolom key — scan dijalankan oleh helper lokal (python3 fb_scan.py) yang membaca Google Maps langsung. Dengan API key: memakai Google Places API (New). Key disimpan hanya di browser ini (localStorage) dan dikirim langsung ke Google. Buat key di Google Cloud Console, aktifkan Places API (New), batasi key ke liemyo.github.io. Hasil maksimal 60 tempat per scan (batas Google).
